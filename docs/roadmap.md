# نقشهٔ راه و وضعیت فازها

## فاز ۰ — تصمیم مسیر ✅

- محیط بررسی شد (سندباکس توسعه؛ Docker در دسترس نیست؛ خروجی شبکه فقط به
  github/pypi/npmjs محدود است).
- مالک **حالت A (Serverless)**، **TypeScript روی Cloudflare Workers**،
  **مخزن جدید برای ربات** و **توکن تلگرام + کلید Gemini** را انتخاب کرد.

## فاز ۱ — MVP ✅

- اسکلت Worker، وب‌هوک با سرّ مشترک، منوی فارسی، ۱۹ فرمان.
- احراز هویت مالک + محدودیت نرخ روی پایگاه‌داده.
- اتصال به D1/SQLite با یک اسکیمای یکسان.
- آمادهٔ استقرار با `wrangler deploy`.

## فاز ۲ — اتصال AI رایگان ✅

- رابط مشترک Provider؛ پیاده‌سازی Gemini، Groq، OpenRouter، DeepSeek، OpenAI، Anthropic.
- فرمان‌های `/provider` `/model` `/test_api` `/usage`.
- سقف رایگان روزانه/ماهانه با هشدار در ۸۰٪ و صف در ۱۰۰٪.

## فاز ۳ — اتصال گیت‌هاب ✅

- GitHub App با امضای RS256 واقعی + PAT به‌عنوان جایگزین.
- `/projects` `/project` `/github`؛ خواندن ساختار، شاخه‌ها، کامیت‌ها و فایل‌ها.

## فاز ۴ — موتور تحلیل و تأیید ✅

- Context builder با بودجهٔ توکن، تحلیل با خروجی JSON اجباری، گزارش فارسی ۹ بخشی.
- تأیید امضاشده (HMAC) با `request_id` + `plan_version` + TTL و دکمه‌های
  تأیید/اصلاح/توضیح/لغو.

## فاز ۵ — اجرا از طریق Actions ✅

- `ai-exec.yml` با لیست مجاز، سقف ۱۵ دقیقه، خروجی ۱۰۰KB، لاگ JSON و کالبک امضاشده.
- Dispatcher با `workflow_dispatch`، خواندن نتیجه و اندازه‌گیری دقیقه.

## فاز ۶ — چرخهٔ کامل ✅

- ساخت شاخه، نوشتن فایل از طریق Contents API، ساخت PR، خواندن نتیجهٔ CI،
  گزارش نهایی و ثبت در حافظهٔ پروژه.

## فاز ۷ — امنیت و استحکام ✅ (تا حد تست خودکار)

- محدودیت نرخ، audit log، محدودیت هزینه، ضد تزریق دستور، حذف اسرار، لیست مجاز.
- باقی‌مانده: بررسی انسانی پس از استقرار (لاگ واقعی، کلیک واقعی در تلگرام).

## فاز ۸ — مستندات ✅

- README فارسی/انگلیسی، راهنماهای تلگرام، GitHub App، کلیدهای رایگان،
  استقرار روی Cloudflare/HF/Oracle، معماری، امنیت، عیب‌یابی و این نقشهٔ راه.

## تصمیمات فنی ثبت‌شده

1. هیچ وابستگی به Docker؛ اجرای کد فقط در GitHub Actions.
2. یک لایهٔ `Sql` برای D1 و SQLite تا کد کوئری یکی بماند.
3. بدون وابستگی خارجی برای JWT/HMAC (WebCrypto).
4. بدون SDK گیت‌هاب (fetch خام) برای کوچک ماندن Worker.
5. خروجی مدل همیشه «داده» است و اعتبارسنجی می‌شود.
